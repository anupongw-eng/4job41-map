QS v41 — Single Popup + Shared QS Activity Anchors

ทดสอบต่อจาก QS v40 (ที่ผ่าน QA)
1. สำรอง qs/index.html บน GitHub
2. อัปโหลด index.html และ QS_Floor1_GroundOverlay.png จาก ZIP นี้เข้าโฟลเดอร์ qs โดยตรง
3. Commit แล้วเปิด GitHub Pages กด Ctrl+F5
4. ทดสอบคลิก marker 1.6 -> 1.8 -> 1.10 ต้องเหลือ popup เดียว
5. วันที่ 5 กดการจัดสวนถาด -> ต้องซูมไป marker 1.10
6. วันที่ 5 กดรีดเต้านมเทียม -> marker 1.9
7. วันที่ 6 ขยายพันธุ์พืช -> 1.10; ฉีดยาเข้ากล้ามเนื้อ -> 1.9
8. ตรวจรายการ QS อีกครั้งบน Chrome และ iPhone

พิกัด Ground Overlay และ marker ทั้ง 11 จุดคงเดิม
กิจกรรม QS ที่จัดอยู่ในห้อง/โรงละคร/ลานหลังโรงละครและยังไม่มีหมุดเฉพาะไม่ถูกโยกไป 1.9 หรือ 1.10 โดยการคาดเดา
หมายเหตุ: ข้อมูลที่เคยบันทึกใน browser ผ่าน localStorage อาจ override ค่าเริ่มต้น; แนะนำทดสอบด้วยแท็บ Incognito ก่อนล็อกเผยแพร่
